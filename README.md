# osnovi_java_1

Базовый проект на Java для изучения основных арифметических и логических операций.

## Что демонстрируется

- Арифметические операции над `int` (+, -, *, /)
- Арифметические операции над `int` и `double`
- Логические операции (<, >, >=, <=)
- Диапазоны типов `float` и `double`
- Переполнение (overflow)

## Требования

- Java JDK 11+

## Запуск

```bash
gradle run
```
